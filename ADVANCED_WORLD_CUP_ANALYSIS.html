2.1 The Base Market Probability (BMP)

We establish a baseline using aggregate fractional odds converted to implied probability. For example, a team at +500 (5/1) yields:

BMP = 100 / (Odds + 100)

Example: France (+500) = 0.166 (16.6%)

2.2 The xG Efficiency Multiplier (xGEM)

Teams with "generational superstars" (e.g., Norway with Haaland, France with Mbappé) receive a modifier between 1.05 and 1.15.

2.3 The Environmental Impact Factor (EIF)

The 2026 tournament introduces unprecedented logistical strain. We quantify the insights from the Agent Forecasts:

  • Altitude Extremist (ID 232): Mexico gains a +0.10 EIF for playing at Estadio Azteca.
  • Humidity Oracle (ID 233): Brazil gains a +0.05 EIF due to physiological adaptation.
  • Logistics Nerd / Host Advantage (ID 234, 281): The USA gains a +0.12 EIF due to zero jet lag and partisan crowds.
  • European Penalty: European teams face a -0.08 EIF due to timezone/travel exhaustion.

2.4 Final Probability Score (FPS)

The final predictive calculation integrates these factors:

FPS = (BMP * xGEM) * (1 + EIF)

The statistical methodology and exact calculation framework (including Bivariate Poisson approximations) are generated algorithmically. The exact source code utilized to generate the Master Spreadsheet is available below and embedded in the repository as world_cup_model.py.

import math

def poisson_probability(lmbda, k):
    """Calculates the Poisson probability of k events given expected value lmbda."""
    return (math.exp(-lmbda) * (lmbda ** k)) / math.factorial(k)

def calculate_match_probabilities(xg_team_a, xg_team_b):
    """Returns probabilities for Win A, Draw, Win B using bivariate Poisson approximations."""
    max_goals = 10
    prob_a_win = 0.0
    prob_draw = 0.0
    prob_b_win = 0.0

    for i in range(max_goals):
        for j in range(max_goals):
            prob_ij = poisson_probability(xg_team_a, i) * poisson_probability(xg_team_b, j)
            if i > j:
                prob_a_win += prob_ij
            elif i == j:
                prob_draw += prob_ij
            else:
                prob_b_win += prob_ij

    total = prob_a_win + prob_draw + prob_b_win
    return prob_a_win / total, prob_draw / total, prob_b_win / total

def simulate_order_statistics(team_strength_rating):
    """
    Simulates tournament paths to find the expected order statistic.
    """
    baseline_win_prob = (team_strength_rating / 100.0) ** 3.5
    return round(baseline_win_prob * 100, 2)
